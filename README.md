# CircuLab: Biblioteca de las cosas del Campus UAB

## Enfoque y tema
- Enfoque: UAB (Campus UAB)
- Tema: economía circular y residuos. Biblioteca de las cosas.
- Grupo: Grupo 5, Gestión de Proyectos (UAB 2026/27)

## Objetivos y finalidad
CircuLab es un espacio donde la comunidad UAB presta y toma prestados
objetos de uso ocasional (taladro, proyector, tienda de campaña, máquina
de coser...). Queremos aumentar el uso de cada objeto, reducir compras
innecesarias y generar menos residuos.

Objetivos:
1. Conocer las necesidades de la comunidad UAB mediante una encuesta.
2. Reunir y catalogar un fondo inicial de objetos.
3. Tener una app de préstamos funcionando (prototipo con AppSheet).
4. Inaugurar la biblioteca en 10 semanas.

## Criterios mínimos de éxito
- Página web (dashboard) publicada en GitHub Pages.
- Prototipo de la app de préstamos con AppSheet.
- Prueba piloto con 20 usuarios.
- Planificación (WBS, Gantt y tablero) actualizada en GitHub Projects.
